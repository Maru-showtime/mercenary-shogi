# イラストの生成プロンプト（通常駒2種＋傭兵13種）

Gemini で画像を作るためのプロンプト集。**1ブロックずつそのままコピペ**して使えます。

生成した画像の置き場所と、`mercenaries.json` への登録方法は
[`README.md` の第4章](README.md) を参照してください。

---

## 使う前に

**アスペクト比 9:16（縦長）** を指定してください。プロンプト本文にも書いてありますが、
Gemini 側に比率の設定があるならそちらでも指定したほうが確実です。

### 背景は「白一色」で作らせること（重要）

当初は「背景を透過させてください」と指示していましたが、**この指示は使わないでください。**

受け取る画像は JPEG です。**JPEG は透明度を保存できない**ので、透明部分が
「透明を表す市松模様」の画像として焼き込まれます。単色の背景なら問題になりません。

実際に起きたこと（2026/09/22）:

- 歩・玉 … 背景が明るい単色扱いになり、**完璧に抜けた**
- 盾歩・先駆歩・斜歩・初手駆けの歩・遊撃香 … **エフェクトに市松模様が残った**

**本当の原因は背景色ではなく「半透明」です。** 光・オーラ・残像を半透明で描くと、
そこに市松模様が混ざった状態で焼き付き、あとから分離できません。
混ざる前の色を計算で求める処理を4通り試しましたが、**すべて失敗しました**
（市松の1マスが 18.673px のように小数で、画面の端へ行くほど位相がずれるため）。

したがって、プロンプトには必ず次の2つを入れてください。

1. **背景は純白 #FFFFFF の一色**（透過と指示しない）
2. **エフェクトは必ず不透明**（半透明・透ける表現を禁止する）

この2つが守られていれば、同梱のツールで確実に抜けます。

```
pip install Pillow
python tools/prepare-sprite.py 生成した画像.jpg mercenaries/shield_pawn
```

画像の**縁からつながっている領域だけ**を背景と判定するので、鎧や刀のような
灰色の部分が一緒に消えることはありません。

### 顔がはっきり見えること

編成画面のカードでは**顔を1.9倍に拡大**して表示します。
顔が小さすぎたり、兜や前髪で隠れていると、カードで何も見えません。
全プロンプトに「顔がはっきり見える」指示を入れています。

## 共通の作風

全部が同じ軍に見えるよう、全プロンプトに次を共通で入れています。

- アニメ調、女性キャラクター、全身、正面向き、9:16の縦長
- 和と洋が混ざったファンタジー将棋の軍勢
- 元になった駒の面影を残す（盾歩なら歩と同じ系統の見た目）
- 背景は純白一色。影・地面・文字・枠を描かない
- エフェクトは不透明

### 進捗

**全15枚そろいました（2026-09）。** 歩・玉の描き直しと、傭兵13種すべての絵がゲームに入っています。

| 印 | 意味 | 対象 |
|---|---|---|
| ✅ 採用済み | ゲームに入っている。作り直し不要 | 歩・玉と、傭兵13種＝**全15枚** |
| 🔁 作り直し | （すべて解消済み） | — |
| （無印） | まだ生成していない | なし |

**🔁 と無印のプロンプトは、新しい条件（白背景・不透明）に書き換え済みです。**
✅ のものは当時の条件のまま残してあります（記録として）。

歩と玉の描き直し用プロンプトには、**「写実的・3DCG的な描写は避ける」指示を明記**しています。
この2枚だけ写実寄りで浮いていたのが描き直しの理由なので、そこを言葉で押さえないと
また同じものが出てきます。

# 通常駒の描き直し（2種）

歩と玉だけ写実寄りで、他の6枚（アニメ調）から浮いているため描き直す。

## ⚠️ 15枚すべてが盤に出ます

**編成で選んだ傭兵は、そのまま盤に並びます。** 編成画面のカードだけではありません。
そのため全15枚に次が当てはまります。

**1. 差し替え・追加のたびに切り出し位置の計算が必要**

盤上では顔の大きさを揃えてあります。絵ごとに顔の大きさは違うので、
`style.css` の `--sprite-zoom` / `--sprite-shift` を計算しないと、
**その駒だけ顔が大きい（小さい）状態**になります。手順は [README.md](README.md) の
「切り出し位置の調整」にあります。

**2. 傭兵は派手でよい、歩は地味に**

傭兵はコスト上限10の制約で、盤に出るのはせいぜい片側1〜3枚です。
**むしろ目立つほうが「傭兵を入れた」と分かって良い**ので、光の軌跡や残像は歓迎です。

一方 **歩は両軍で18枚**並びます。派手だと盤面がうるさくなるので、地味にします。

**3. 他の駒と色がかぶらないこと**

盤上には40個の駒が並びます。見分けは**髪と服の色**が担っているので、
既存の色に寄せると判別できなくなります。現在の割り当て:

| 駒 | 色の特徴 |
|---|---|
| 香 | 金髪ポニーテール＋白銀の甲冑 |
| 桂 | 二角帽＋青と金の軍服＋白馬 |
| 銀 | 黒髪ボブ＋白の和装に黒袴 |
| 金 | 黒い高冠＋紺の官服 |
| 飛 | 水色ツインテール＋白いジャケット |
| 角 | 桃色の髪＋白と桃の機械翼 |

歩は**黒髪＋銀の鎧**のままにしますが、銀（黒髪＋白和装）と紛れやすいので、
**深緑のマント**を足して区別しやすくしています。深緑は他のどの駒にも使っていません。

### 差し替えたあとに必ずやること

1. `assets/sprites/P.webp` / `K.webp` を置き換える
2. **顔幅と目線の高さを測り直し、`style.css` の `--sprite-zoom` / `--sprite-shift` を再計算する**

手順を飛ばすと、その駒だけ顔の大きさが揃わなくなります。

## 生成した画像の登録

1. `assets/sprites/mercenaries/` に置く（ファイル名は傭兵のID。例: `shield_pawn.webp`）
2. `src/data/mercenaries.json` の該当する傭兵に1行足す

```json
"shield_pawn": {
  "name": "盾歩",
  "image": "mercenaries/shield_pawn.webp",
  ...
}
```

3. **顔幅と目線を測り、`style.css` に切り出し設定を足す**

```css
.piece-sprite-merc-shield_pawn {
  --sprite-zoom: 2.10;
  --sprite-shift: 35.0%;
}
```

3 を省くと元の駒の値が使われ、その傭兵だけ顔の大きさがずれます（表示は壊れません）。

**`image` を書かなければ元の駒の絵のまま**なので、できたものから順に差し替えられます。
13種すべて揃うまで待つ必要はありません。

なお、**取られたり成ったりして能力を失った傭兵は、元の駒の絵に戻ります。**
ルールがそのまま見た目に出るようになっています。
