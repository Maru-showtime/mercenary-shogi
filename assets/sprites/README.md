# 駒のイラストの差し替え方

このフォルダに画像を置くだけで、盤上の駒の絵が入れ替わります。コードの変更は不要です。

## 1. ファイル名

**駒1種につき1ファイル。名前は下の8つに固定**です。

| ファイル名 | 駒 |
|---|---|
| `P` | 歩 |
| `L` | 香 |
| `N` | 桂 |
| `S` | 銀 |
| `G` | 金 |
| `K` | 玉 |
| `R` | 飛 |
| `B` | 角 |

**成り駒の絵は不要です。** 成った駒は元の駒と同じ絵に金色のオーラが重なります
（と金＝歩の絵、龍＝飛の絵）。8枚だけ用意してください。

## 2. 置き方（2通り。どちらでもよい）

### A. 1枚を両陣営で使う（おすすめ・8枚で済む）

```
assets/sprites/
├─ P.png
├─ L.png
├─ N.png
├─ S.png
├─ G.png
├─ K.png
├─ R.png
└─ B.png
```

先手・後手の区別は、**駒の五角形の向き（上下反転）と縁の色**が担当します。
キャラの絵自体は両陣営で同じで問題ありません。

### B. 陣営ごとに別の絵を使う（16枚）

```
assets/sprites/
├─ sente/     先手用
│  ├─ P.png … B.png
└─ gote/      後手用
   └─ P.png … B.png
```

`sente/` フォルダが存在する場合、そちらが優先されます。
片方の陣営だけ用意して、残りは直下の共通ファイルを使う、という混在も可能です。

## 3. 画像の仕様

**全身画像をそのまま渡せます。** 縦長の画像（縦が横の1.3倍以上）は自動的に
「全身画像」と判定され、盤上では**拡大して上にずらし、上半身だけが見える**ように表示されます。
全身を小さく表示すると盤上では何の駒か分からないためです。

| 項目 | 推奨 |
|---|---|
| 形式 | **WebP / PNG（背景透過）** または SVG。読み込みは webp → png → svg の順に探します |
| サイズ | 全身画像なら高さ400〜600px程度。上半身だけを描いた絵なら48×48px前後 |
| 背景 | **必ず透過**。背景を塗ると駒の木目と漢字が隠れます |
| 構図 | 全身・上半身どちらでも可（縦横比で自動判定） |

同梱の変換ツールは既定で **WebP** を書き出します。PNGと比べて約1/5のサイズになり、
盤上の表示サイズでは劣化が分かりません（実測でPNG 1.63MB → WebP 0.35MB）。
PNGが必要な場合は `--png` を付けてください。

### 切り出し位置の調整（顔の大きさを揃える）

絵によって「画像の高さに対する顔の大きさ」はまったく違います。実測すると
**金は歩の2.2倍**あり、盤に並べると金だけ顔が大きく浮いて見えました。
そのため拡大率は駒ごとに計算して `style.css` に書いてあります。

```css
.piece-sprite-P {
  --sprite-zoom: 2.27;   /* 大きくすると顔に寄る */
  --sprite-shift: 38.9%; /* 小さく（マイナス方向に）すると上が見える */
}
```

差し替えたら、その絵の**顔幅**と**目線の高さ**を測って計算し直してください。

```
--sprite-zoom  = 68 ÷ 顔幅                          顔幅をマスの13%に揃える
--sprite-shift = 57.4% − 目線の高さ ÷ 画像の高さ × zoom  目線をマスの56.8%に揃える
```

顔幅は「左の頬から右の頬まで」、目線は「瞳の中心の高さ」を画像の上端から測ります。
どちらも元画像のピクセル数で測れば十分です。

現在の実測値（いずれも画像の高さは 480px）:

| 駒 | 画像サイズ | 顔幅 | 目線の高さ | zoom | shift |
|---|---|---|---|---|---|
| P 歩 | 206×480 | 30 | 39 | 2.27 | 38.9% |
| L 香 | 284×480 | 37 | 73 | 1.84 | 29.4% |
| N 桂 | 286×480 | 33 | 45 | 2.06 | 38.1% |
| S 銀 | 228×480 | 37 | 43 | 1.84 | 40.9% |
| G 金 | 278×480 | 67 | 109 | 1.01 | 34.5% |
| K 玉 | 277×480 | 42 | 110 | 1.62 | 20.3% |
| R 飛 | 379×480 | 40 | 57 | 1.70 | 37.3% |
| B 角 | 315×480 | 45 | 113 | 1.51 | 21.9% |

### 横に広い絵でも切り詰めなくてよい

**絵は駒の五角形の輪郭で切り抜かれます。** 飛のツインテールや角の翼のように
横へ大きく広がる構図でも、はみ出した部分は輪郭に沿って自然に切れるので、
絵の側で余白を詰めたり左右を切ったりする必要はありません。

上の式の定数 68 と 57.4% は、絵を見せる窓の大きさ（`style.css` の
`--piece-w` / `--piece-h`）から決まっています。**駒の大きさを変えたら
この2つの定数も計算し直してください。**変えないと顔の大きさが揃わなくなります。

**桂だけは妥協しています。** 顔を他と同じ大きさにすると騎馬はほぼ枠の外に出ます。
40個の駒が並ぶ盤面では顔の大きさが揃っている方が見分けやすいので、馬より顔を優先しました。
馬を見せたい場合は `--sprite-zoom` を 1.7 前後まで下げてください（顔は小さくなります）。

### 背景が透過していない画像の下ごしらえ

市松模様が焼き込まれたJPEGなど、透過していない画像は同梱のツールで処理できます。

```
pip install Pillow
python tools/prepare-sprite.py 元画像.jpg P
```

背景を透過し、余白を切り詰め、Web用に縮小して `assets/sprites/P.png` に保存します。
画像の**縁からつながっている領域だけ**を背景と判定するので、銀の鎧や刀のような
灰色の部分が一緒に消えることはありません。

### 駒の描き分けについて

盤上では40個の駒が並ぶので、**ぱっと見で区別できること**が何より重要です。
顔の大きさは揃えてあるので、区別は**髪の色・服の色・シルエット**が担当します。

| 駒 | 現在の絵 |
|---|---|
| 歩 | 黒髪＋銀の鎧 |
| 香 | 金髪ポニーテール＋白銀の甲冑 |
| 桂 | 二角帽の騎兵＋白馬 |
| 銀 | 黒髪＋白の和装 |
| 金 | 黒の高冠＋紺の官服 |
| 玉 | 黄金の玉座 |
| 飛 | 水色ツインテール |
| 角 | 桃色の髪＋機械翼 |

色で見分けている以上、**同系色の絵を2つ入れると盤上で混乱します。** 差し替えるときは
他の7枚と色がかぶっていないか確認してください。

## 4. 傭兵ごとの専用イラスト（任意）

編成画面のカードには、既定では**元の駒の絵**が出ます（盾歩なら歩の絵）。
傭兵ごとに別の絵を用意したくなったら、画像を置いて `src/data/mercenaries.json` に1行足すだけです。

```
assets/sprites/mercenaries/shield_pawn.webp   ← 画像を置く
```

```json
"shield_pawn": {
  "name": "盾歩",
  "image": "mercenaries/shield_pawn.webp",   ← この1行を足す
  ...
}
```

パスは `assets/sprites/` からの相対です。**`image` を書かなければ元の駒の絵のまま**なので、
描けたものから順に差し替えていけます。全部揃うまで待つ必要はありません。

画像の仕様は通常の駒と同じ（縦長の全身画像で可）。ただし**編成画面のカードでしか使われない**ため、
盤上は元の駒の絵のままです。盤は40個並ぶので、傭兵ごとに絵を変えると
かえって駒種が見分けにくくなるという判断です。

## 5. SVGを使う場合の色の差し替え（任意）

SVGはインラインで読み込まれるため、塗りに CSS 変数を使うと**1枚で陣営ごとに色を変えられます**。

```svg
<rect x="10" y="20" width="4" height="1" fill="var(--sp-armor, #4a7fd4)"/>
```

| 変数 | 意味 | 先手 | 後手 |
|---|---|---|---|
| `--sp-armor` | 鎧・兜の主色 | `#4a7fd4` | `#d45a5a` |
| `--sp-armor-dark` | その影 | `#2f5aa8` | `#a83c3c` |
| `--sp-armor-light` | そのハイライト | `#7aa8ea` | `#eb8c8c` |

PNGではこの仕組みは使えません（PNGで陣営ごとに色を変えたい場合は上の「B」の置き方にしてください）。

## 6. 差し替えの手順

1. 古い画像を**削除**する（同じ名前で拡張子だけ違うファイルが残っていると紛らわしいため）
2. 新しい画像を上の名前で置く
3. `style.css` の `--sprite-zoom` / `--sprite-shift` を計算し直す（上の「切り出し位置の調整」）
4. ブラウザを再読み込みする
5. ヘッダーの「イラスト」チェックで漢字表示と切り替えて確認する

## 7. 素材のライセンス

**入手した素材は必ず `assets/CREDITS.md` に出典・作者・ライセンスを記載してください。**
公開リポジトリなので、CC-BY などの表示義務がある素材は記載しないと規約違反になります。

NC（非商用）条件の素材は、広告なしの個人公開なら問題ありませんが、避けた方が無難です。

## 8. `tools/gen-sprites.mjs` について

開発初期に仮のドット絵を生成していたスクリプトです。**現在は使っていません。**
消しても動作に影響はありません（背景透過に使う `tools/prepare-sprite.py` は残してください）。
